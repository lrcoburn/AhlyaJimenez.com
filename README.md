# AhlyaJimenez.com

Personal portfolio and commission website for **Ahlya Jimenez**, a 16-year-old equine portrait artist.

## Pages

| File | Description |
|------|-------------|
| `index.html` | Homepage — hero, about/timeline, gallery, commission CTA |
| `commission.html` | Commission request form with photo upload |
| `styles.css` | Shared stylesheet |

## Features

- **About section** — Ahlya's art journey timeline (1st grade → 6th grade → today)
- **Gallery** — showcase of portrait work
- **Commission request form** — visitors can submit their name, email, horse's name, portrait type, preferred medium, size, and upload reference photos (drag-and-drop supported)

## Deploying

Drop the three files onto any static host (GitHub Pages, Netlify, Vercel, etc.).
For real form submissions, wire `commission.html` up to a service such as [Formspree](https://formspree.io) or [Netlify Forms](https://docs.netlify.com/forms/setup/).
